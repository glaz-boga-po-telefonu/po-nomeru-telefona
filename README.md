# Глаз Бога по номеру телефона: как начать поиск

Чтобы искать по телефону, отправьте номер с кодом страны в соответствующий раздел бота. Если он встречался в доступных записях, в ответе могут быть имена, связанные аккаунты или другие сведения о контакте. По одному номеру нельзя автоматически сделать вывод о нынешнем владельце: запись могла быть создана несколько лет назад.

## Как ввести номер

Используйте полный номер в международном формате. Проверьте код страны и цифры перед отправкой. Для статьи не нужен реальный номер в примере: достаточно помнить, что короткий местный формат может оказаться неоднозначным.

## Как читать совпадения

Посмотрите, когда появилась запись и к какому аккаунту она относится. Если видите имя или ник, сравните их с другими признаками. Несколько записей могут относиться к разным владельцам одного номера. Контактная метка из старой телефонной книги показывает, как номер был сохранён у кого-то в тот период; она не подтверждает личность нынешнего абонента.

Если результат связан с Telegram, пригодится числовой ID аккаунта. Он помогает отличать историю одного профиля от похожего ника. Сведения о скрытом в профиле номере тоже могут появиться из более ранней связи в сохранённых данных, когда она есть.

## Если совпадений нет

Сверьте формат и повторите запрос без лишних символов. Отсутствие записи не говорит ничего определённого о человеке или номере. Для поиска нужен совпадающий источник, а его может не быть.
